# Locked three-seed formal test

This campaign performs the user-authorized one-time test evaluation of the
already frozen validation-selected TolerantECG, HILA-K, and HILA-K+LRA
checkpoints for seeds 42/46/55 and all six tasks. It does not train, select,
or tune any model on test data. Threshold-dependent metrics use the fixed
probability threshold 0.5.
